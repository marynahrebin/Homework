Команди термінала та Git

Список основних команд, які ми розглянули під час практичної роботи:

  • ssh-keygen -t ed25519 -C "your_email@example.com" — генерація SSH-ключа
  • cat ~/.ssh/id_ed25519.pub — перегляд та копіювання публічного ключа
  • git config --global user.name "Name" — налаштування імені в Git
  • git config --global user.email "email" — налаштування пошти в Git
  • git clone [url] — клонування репозиторію на комп'ютер
  • git add . — додавання змінених файлів у чергу на збереження
  • git commit -m "message" — збереження (знімок) змін із коментарем
  • git push — відправка комітів на GitHub у хмару
